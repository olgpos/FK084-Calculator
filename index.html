Aprēķinā izmantota īsākā diagonāle
Parādīt izmantotās formulas

Vidējais galvas apkārtmērs

C̄ = (C1 + C2 + C3) / 3

Cranial Ratio

CR = (ML / AP) × 100 %

Cranial Vault Asymmetry

CVA = |D1 − D2|

Cranial Vault Asymmetry Index

CVAI = |D1 − D2| / min(D1, D2) × 100 %

Aptuvenais elipses apkārtmērs

C ≈ π [3(a+b) − √((3a+b)(a+3b))]
a = AP / 2     b = ML / 2

Aptuvenais apkārtmērs, kas aprēķināts no AP un ML, ir ģeometriska aproksimācija un neaizstāj tiešu galvas apkārtmēra mērījumu.
